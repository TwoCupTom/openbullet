# Chant Engineering — Website Redesign

A modern, sleek redesign concept for [chantengineering.com](https://chantengineering.com/).

## Design direction — "Engineering under load"

An instrument-panel visual identity built around Chant's world of heavy-duty
testing machinery. The page reads like an engineering spec sheet:

- **Palette** — dark-first gunmetal ground with a single bold **signal-orange**
  accent for force/action, and a disciplined **blueprint-cyan** used only for
  measurement, data readouts and technical linework. Full polished light theme
  included (auto-detects OS preference; manual toggle in the header).
- **Type** — heavy system grotesque for display, system sans for body, and a
  **monospace** voice for all data, eyebrow labels, part-number tags and stat
  readouts. No web-font downloads (fully self-contained / CSP-safe).
- **Motion** — animated blueprint grid, count-up stat readouts, an animated
  DataTEST™ load gauge, scroll reveals, and an industries marquee. All motion
  respects `prefers-reduced-motion`.

## Sections

Sticky glass header · hero with live load-gauge panel · industries marquee ·
7-line product catalog · capabilities with a blueprint drawing · industries
grid · service & support · by-the-numbers stats · contact CTA · footer.

## Content

Copy and product lines are drawn from Chant's actual business — proof testing
machines, hydrostatic test systems, reeling machines, swagers & dies, load
monitoring, DataTEST™ software and government/military work — serving aerospace,
defense, oil & gas, construction, rigging, entertainment and industrial markets.

## Usage

`index.html` is fully self-contained (no build step, no external assets). Open
it directly in any browser or drop it on any static host.
